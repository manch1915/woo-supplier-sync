# Supplier Sync для WooCommerce

Плагин WordPress, который держит каталог WooCommerce в синхроне с поставщиками. Читает YML и XML, прайсы CSV и Excel, JSON API и сайты поставщиков, создаёт и обновляет товары, цены, остатки, фото, атрибуты и вариации по расписанию.

**Демо:** магазин на [supplier-sync.narcisbin.com](https://supplier-sync.narcisbin.com), плагин в [админке](https://supplier-sync.narcisbin.com/wp-login.php) под `demo` / `demo`. Там можно запускать синхронизацию и сухой прогон, каждую ночь данные возвращаются к исходным.

Подробное описание на английском: [README.md](README.md).

## Что умеет

У каждого поставщика свой профиль: откуда брать фид, что лежит в какой колонке, как его атрибуты и категории ложатся на ваши и какие поля ему разрешено менять. Предпросмотр читает первые строки с текущими настройками, поэтому товары видно ещё до первого запуска.

Если один товар есть у нескольких поставщиков, плагин сводит их по EAN, а затем по артикулу производителя. Остатки суммируются, цену задаёт самый дешёвый поставщик, у которого товар есть, а название, описание и фото остаются от того, кто привёз товар первым. Предложения с общей моделью или `group_id` становятся одним вариативным товаром, а отличающиеся атрибуты (цвет, размер) становятся атрибутами вариаций.

Ещё в плагине есть:

- наценки по поставщику, категории и диапазону закупки, фиксированная надбавка, минимальная маржа, округление «до 90», до ,99 или до целого, курсы валют; калькулятор рядом с правилами сразу считает по несохранённым правкам
- политика нулевых остатков: показывать «нет в наличии», скрыть из каталога или перевести в черновики; «под заказ» из YML превращается в предзаказ
- фото в фоне с уменьшением и конвертацией в WebP, каждое изображение хранится один раз, даже если два поставщика прислали его по разным адресам
- большие фиды: запуск идёт цепочкой коротких задач Action Scheduler с бюджетом времени, неизменившиеся предложения пропускаются по хешу
- сухой прогон: список всех товаров, которые изменятся, со старыми и новыми значениями, и применение в один клик
- защита от сломанного фида: если за раз пропало больше 30% предложений, с продажи ничего не снимается, а в журнале объясняется почему
- журнал по каждому товару и отчёт в Telegram или на почту после запуска
- кнопка «Сравнить» в карточках (до 4 товаров, отличия подсвечены) и фильтры по атрибутам на ядровых блоках WooCommerce
- команды WP-CLI для системного cron, совместимость с HPOS, интерфейс на русском и английском

## Запуск

```bash
docker compose up -d
```

Магазин: http://localhost:8080, плагин: http://localhost:8080/wp-admin/admin.php?page=supplier-sync, демо-вход `demo` / `demo`. Пароль администратора печатается в `docker compose logs setup`.

В демо три выдуманных поставщика: Nordline (электроника, YML в рублях), Pinecrest (снаряжение, CSV в евро с запятыми в ценах) и Volta (сайт, который разбирает парсер). Четыре товара Volta совпадают с Nordline по EAN и сливаются с ними.

Деплой на сервер: [docs/deploy.md](docs/deploy.md).
